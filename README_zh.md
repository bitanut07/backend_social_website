# Artly Backend

Đây là tên file được giữ lại từ bộ khung Goravel để tránh làm hỏng các liên kết
cũ. Toàn bộ tài liệu dự án được viết bằng tiếng Việt tại [README.md](./README.md).

Artly Backend dùng Goravel và PostgreSQL 17, cung cấp API cho bảng tin bài thi vẽ,
reaction, tin nhắn trực tiếp và trợ lý thống kê theo chủ đề. Dùng
[`sql.sql`](./sql.sql) với `psql` để tự khởi tạo database, schema và dữ liệu mẫu.
